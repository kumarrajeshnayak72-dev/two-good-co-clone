🎨 Two Good Co. Website Clone

A responsive front-end clone of the Two Good Co. website built using HTML, CSS, and JavaScript. This project focuses on recreating the modern design, smooth user experience, and responsive layout of the original website while improving front-end development skills.

🚀 Features

- Responsive design for mobile, tablet, and desktop
- Modern and clean user interface
- Smooth scrolling effects
- Interactive elements and animations
- Custom navigation bar
- Product showcase sections
- Optimized layout and styling

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Responsive Web Design
- Flexbox
- CSS Grid
